- [Microsoft Windows 11 공식 다운로드](https://www.microsoft.com/software-download/windows11)
- [Microsoft Windows 10 공식 다운로드](https://www.microsoft.com/software-download/windows10)

파일명은 자유롭게 정할 수 있습니다. Windows 설치 시 에디션, 대상 디스크, 파티션은 화면에서 직접 선택하세요.
