# Linux 이미지

v0.1.0은 Ubuntu, Debian, Fedora, 기타 배포판의 ISO 보관 위치와 일반 부팅을 안내합니다. 자동 설치 템플릿은 포함하지 않습니다. ISO는 각 배포판 공식 다운로드 페이지에서 직접 받으세요.

- [Ubuntu 공식 다운로드](https://ubuntu.com/download)
- [Debian 공식 다운로드](https://www.debian.org/distrib/)
- [Fedora 공식 다운로드](https://fedoraproject.org/workstation/download)

[Ventoy 공식 Auto Install 문서](https://www.ventoy.net/en/plugin_autoinstall.html)는 Ubuntu Server 20.x 이후 cloud-init, Debian preseed, Fedora/RHEL 계열 Kickstart, SUSE AutoYaST를 나열합니다. Ubuntu Server 20.x 이전은 preseed로 구분합니다. 이 키트에는 해당 템플릿이 없으며 [Roadmap](../ROADMAP.md)의 검토 후보입니다. 공식 목록에 Ubuntu Desktop 항목은 없어 지원을 주장하지 않습니다.
